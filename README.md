# numerical-methods-cpp

Numerical methods in C++.

## Files

- `bisection_method.cpp` — Bisection method
- `newton_raphson.cpp` — Newton-Raphson method
- `secant_method.cpp` — Secant method
- `lagrange_interpolation.cpp` — Lagrange interpolation
- `newton_divided_difference.cpp` — Newton's divided difference interpolation
- `trapezoidal_rule.cpp` — Trapezoidal rule integration
- `simpsons_one_third.cpp` — Simpson's 1/3 rule integration
- `simpsons_three_eighth.cpp` — Simpson's 3/8 rule integration
- `runge_kutta.cpp` — 4th-order Runge-Kutta (RK4) ODE solver
- `power_method.cpp` — Power method for dominant eigenvalue

## Run

```bash
g++ bisection_method.cpp -o bisection_method
./bisection_method
```
